# HA Camera Face ID (Free & Open Source)

Add-on Home Assistant nhận diện khuôn mặt cục bộ (Local AI) từ các camera entity trong Home Assistant bằng AI **InsightFace**.

## Tính năng nổi bật
- **100% Miễn phí & Mã nguồn mở**: Không cần bất kỳ License Key hay kết nối Internet nào.
- **Tự lấy Camera từ Home Assistant**: Kết nối qua Home Assistant Supervisor API.
- **AI InsightFace chuẩn công nghiệp**: Sử dụng model `buffalo_sc` nhận diện chính xác >99%.
- **Tích hợp MQTT & Auto Discovery**: Tự động bắn thông báo và tạo Sensor trên Home Assistant.
- **Giao diện Web UI Ingress mượt mà**: Quản lý khuôn mặt, xem lịch sử và test trực tiếp ngay trên dashboard.

## Cài đặt vào Home Assistant
1. Vào **Settings → Add-ons → Add-on Store** trong Home Assistant.
2. Thêm kho lưu trữ (Repository URL): `https://github.com/HuyTranst/ha-camera-face-id`
3. Tìm **HA Camera Face ID (Free Open Source)** và bấm **Install**.
4. Khởi chạy Add-on và bấm **Open Web UI**.
